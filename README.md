# java-racingcar-precourse


## 기능 요구사항

### 입력

- [ ] 경주할 자동차 이름 입력
- [ ] 자동차 이름을 쉼표(`,`) 기준으로 구분
- [ ] 자동차 이름이 5자 이하인지 검증
- [ ] 시도할 횟수 입력
- [ ] 잘못된 입력값에 대해 `IllegalArgumentException` 발생

### 자동차 경주

- [ ] 입력받은 시도 횟수만큼 자동차 경주 반복
- [ ] 각 자동차마다 0~9 사이의 무작위 값 생성
- [ ] 무작위 값이 4 이상인 자동차만 한 칸 전진
- [ ] 한 회차마다 모든 자동차의 이동 수행

### 출력

- [ ] 각 경주 회차별 자동차 이름과 이동 결과(`-`) 출력
- [ ] 모든 경주 종료 후 최종 우승자 출력
- [ ] 공동 우승자가 존재할 경우 쉼표(`,`)로 구분하여 출력

### 객체별 기능 및 책임

#### Application

- 애플리케이션 실행 
- 애플리케이션 실행에 필요한 객체 생성 및 연결

#### CarRaceController

- 자동차 경주 애플리케이션의 전체 실행 흐름 조율
- 입력 요청
- 입력값 파싱
- 입력받은 시도 횟수만큼 서비스 호출
- 출력 요청

#### CarRaceService

- 자동차 경주 유스케이스 수행

#### InputView

- 경주할 자동차 이름 입력
- 시도할 횟수 입력

#### OutputView

- 자동차 경주 실행 결과 출력
- 자동차 이름과 이동 거리를 출력 형식으로 변환
- 최종 우승자 출력
- 공동 우승자를 요구된 출력 형식으로 변환

#### Car

- 자동차 이름과 이동 거리 관리
- 주어진 이동 조건 값에 따라 전진
  
#### Cars

- 여러 Car 객체를 컬렉션으로 관리
- 경주 시 모든 자동차의 이동 수행
- 자동차들의 경주 후 상태 반환
- 가장 멀리 이동한 자동차 탐색
- 최종 우승 자동차 반환
